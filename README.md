# My Node App

This project is developed using Node.js and Express.js framework.

## Project Description
This is a simple web application that runs a local server and displays a greeting message in the browser.

## Technologies Used
- Node.js
- Express.js
- JavaScript

## Features
- Simple Express server
- Browser output display
- Localhost execution

## How to Run
1. Install Node.js
2. Open terminal in project folder
3. Run command:
   npm install express
4. Start server:
   node index.js
5. Open browser:
   http://127.0.0.1:8000
